# The Long Watch

A 365-day lighthouse keeper's journal. Write each day. Grow something from your words.

**Play now:** https://terrywhitakergithub.github.io/thelongwatch/

## Install

**Android (Chrome):** Open the link above → tap the browser menu → *Add to Home Screen*

**iOS (Safari):** Open the link above → tap the Share button → *Add to Home Screen*

**Desktop:** Open the link in Chrome → click the install icon in the address bar

## About

Single-file, offline-capable literary game. No account required. Your journal stays on your device.
